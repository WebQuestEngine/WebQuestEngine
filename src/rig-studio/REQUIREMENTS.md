# Character Rig Studio

## UX vision

### Principles

Character Rig Studio should follow several core principles.

#### Artwork first.
The user's character artwork is always the primary visual focus.

#### Direct manipulation.
Users should interact with joints, layers, and artwork directly instead of configuring abstract properties whenever possible.

#### Smart defaults.
Symmetry, joint hierarchy, layer attachment, and common anatomical relationships should be inferred automatically.

#### Progressive complexity.
Simple characters should remain simple to rig. Advanced capabilities should appear only when needed.

#### Immediate feedback.
Users should be able to test the rig throughout the setup process rather than completing a long configuration workflow before seeing results.

#### Non-destructive editing.
Artwork, rig placement, layer assignment, and hierarchy should remain editable at all times.
